# 調理
切る + 焼く = ジャガバターマセイモ
切る + 揚げる = マセイモチップス
焼く = ベイクドマセイモ
揚げる = フライドマセイモ
焼く + 揚げる = 焦げマセイモ

# ザコ・マセイモ
## 動作
プレイヤーが範囲内にいるとき、歩いて近づいてくる
近づいてきて攻撃範囲に触れるとダメージ
焼く・揚げるの攻撃を受けたとき、パニックで走り出す

# カタイモ
## 動作
丸まって転がりながら近づいてくる
触れるとダメージ
切る攻撃を弾く
焼く・揚げるの攻撃をすることによって丸まるのをやめ、一定時間スタンする
スタン中に攻撃をすることで攻撃が通る

# ドクドクイモ
## 動作
一定時間ごとに毒をまき散らす
倒すと毒をまき散らして爆発する
揚げるの攻撃を受けると無毒化する

# マセイモ・シャリ・スシ
商店街の最深部、寿司屋の跡地で待ち受ける。
## 動作
ネタ（大トロ部分/手にあたる）： プレイヤーに目がけて大トロを叩きつけたり、飛ばしてくる（遠距離攻撃）。「切る」攻撃を重ねてネタを切り離すことで、遠距離攻撃を封じ込める。

ガリ・ワサビ（足にあたる）： 突進（接近攻撃）の原動力。ここを「焼く」または「揚げる」ことで突進を封じ込める。

シャリ（本体）： ネタやガリを無力化するとダウン。露出した巨大なシャリ（芋）を「切る＋焼く」などのコンボで調理していくことでトドメを刺す。

# KINGマセイモ
異常警報の赤ランプが鳴り響くコントロールルームで激突。
撃破後、プレイヤーの料理人3人を吸引口から体内に吸い込む展開へ繋げる。
## 動作
前半戦（ムカデ形態）： 機械と融合した長い体で、工場の床や壁（ダクト）を掘って出入りしながら突進してくる。

後半戦（分裂・バグの予兆）： 残り体力が少なくなると、工場の警報が最大音量になり、機械から大量のザコイモ（カタイモやドクイモ）を射出して全方位攻撃を仕掛けてくる。

調理法： 突進時に露出する関節（芋の節）を「揚げる」ことで、マシンの潤滑油ごとカラッと固めて動きを止め、スタン中に大ダメージを与える。

# 監視イモ
無数の文字列や数式が発光して流れる中、巨大な「目」のような形をした心臓がプレイヤーを監視している。文字マセイモを呼び出す警報装置でもある。
## 動作
監視レーザー： 心臓の「目」が見える範囲のプレイヤーに、数式データのレーザービームを放ってくる。サイバー空間の障害物（バグデータの壁）に隠れながら近づく必要がある。

マルコフ連鎖の鎖（防御）： 正面からの攻撃は「確率の鎖」によってすべて弾かれる。レーザーを避けて視界の反対側（死角）に回り込んで攻撃することで、心臓をダウン（連鎖の一時中断）させられる。

警報と召喚（復活時）： ダウンから復帰する際、けたたましい警報エフェクトとともに「文字マセイモ（ザコ）」を大量に呼び出す。

特殊決戦ルール： ダウン中に、指定された「文字マセイモ」を順番に調理（例：切る→焼く→揚げる）してコンボを繋ぐことで、マルコフ連鎖の鎖を完全に断ち切り、撃破（エンディングのフライドポテト大爆発）へ移行する。
